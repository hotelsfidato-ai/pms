# Research notes behind SELLING-IN-INDIA.md

Five notes, written on 25 September 2026 by research helpers of the selling-in-India audit, from web reading only (no project code or data was sent anywhere). Each rule carries its primary source, date, link, status and a confidence level; each note ends with what is not yet in force and what is unresolved.

| File | Covers |
|---|---|
| `gst.md` | Hotel GST after 22 Sep 2025, invoices and credit notes, e-invoicing, returns, OTAs, liquor VAT (MH, UP, HP), FSSAI |
| `income-tax-and-form-iii.md` | Income-tax Act 2025 section map, cash and PAN rules, Form III (was Form C), state guest registers, service charge |
| `data-protection-and-aadhaar.md` | DPDP Act and Rules 2025 with dates, the hotel's and the processor's duties, Aadhaar, SPDI Rules |
| `cert-in-and-payments.md` | CERT-In Directions and later guidance, what buyers ask for, RBI payment rules, UPI |
| `selling-software.md` | GST and TDS on selling the software, MSME, contracts, trade mark, open-source licences |

Where a note mentions `scratchpad/law/`, that was the helper's temporary folder of downloaded source documents; it is not kept. Use the links in the notes.
