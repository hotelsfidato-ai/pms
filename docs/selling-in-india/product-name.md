# The product's new name: a first screen

**The owner's picks for the lawyer's trade mark search: Tomai, Yadou, Kyado.**

Written 27 September 2026 by the product-name session (D25-32, D27-14; A14 in
`docs/SELLING-IN-INDIA.md`), on `cp6` at `357c1bb`. Web reading only: only the
candidate names were searched, and nothing from the project's code or data was sent anywhere.

> **This is a first screen, not a legal clearance.** It looked for hotel,
> hospitality and software brands that already use each name, and asked the
> three domain registries whether the name is taken. It did **not** search the
> Indian trade mark register: IP India's public search needs a CAPTCHA, which
> this session may not solve. The lawyer runs that search, in class 9
> (software) and class 42 (SaaS), with class 35 optional, including the
> register's phonetic search. Fees and the ® rule are in A14.

## What the owner asked for (27 September)

- **Feel:** an invented word, **Japanese-sounding** ("I like Japanese work").
- **Influvate in the name:** no. The product stands alone; "by Influvate" can
  sit under it.
- **Languages:** must read and sound well in any Indian language.
- **Length (second answer):** one word, **4 or 5 letters**.

Japanese syllables (ka, to, ya, do…) are open consonant-vowel pairs that every
Indian language already has, so the names are built from Japanese hospitality
words and then changed, so that none is a real word:

## How each name was checked

1. **Domains:** each registry's own public lookup (RDAP) for `.com`
   ([Verisign](https://rdap.verisign.com/com/v1/domain/example.com)), `.in`
   ([NIXI](https://rdap.nixiregistry.in/rdap/domain/example.in), found through
   [IANA's list](https://data.iana.org/rdap/dns.json)) and `.app`
   ([Google Registry](https://pubapi.registry.google/rdap/domain/example.app)).
   "Registered" only means someone holds it. Where a `.com` answered, its page was
   opened to see whether it is parked, for sale or a live business.
2. **Brands:** a web search per name for software, apps, hotels and companies
   using it or something that sounds like it.
3. **Status:** **clean** = nothing found in hotels, hospitality or software;
   **risky** = something close in software or hotels, or a real word the
   register may call descriptive; **taken** = used by software or a well-known
   brand.

**Limits:** the search tool reads a mostly US index, so a business that exists only in
India may not show; the Ministry of Corporate Affairs' company names were not
searched; **no name was checked with native speakers** for an awkward meaning
in Hindi, Marathi, Bengali, Tamil, Telugu, Kannada or Malayalam. Ask staff
who speak them before filing.
